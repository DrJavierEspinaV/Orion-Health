# ORDENAUTAS

Aplicación familiar de misiones, energía, rangos y recompensas.

## Versión vigente

V1.6 — piloto con doble interfaz parental.

## Estructura de versiones

La carpeta de la aplicación mantiene una ruta estable: `apps/ordenautas/`. La versión operativa se registra en `VERSION.txt`; no debe incorporarse al nombre del directorio.

## Persistencia del piloto

Los datos se almacenan localmente en el dispositivo durante el piloto familiar.
